# 项目概述

## 项目目标

构建一款面向写作者的 Markdown 桌面编辑器，提供柔和简洁的视觉体验和 Typora 级别的所见即所得编辑能力。

## 目标用户

- 日常写作者、博客作者
- 技术文档撰写者
- 喜欢 Markdown 但嫌 Typora 收费的用户
- 注重界面美观和书写体验的用户

## 核心场景

1. **单文档写作** — 打开一个 .md 文件，安静地写作，保存
2. **工作区管理** — 打开一个文件夹，在其中管理多个文档
3. **导出分享** — 将 Markdown 导出为 PDF 或 HTML

## 产品原则

### 1. 文字优先

界面为文字服务，不为装饰。所有视觉元素都应退让于用户的写作内容。

### 2. 所见即所得

用户输入的 Markdown 语法应该立即呈现为渲染后的效果，不需要切换模式或查看侧边预览。

### 3. 柔和不刺眼

配色方案应经过精心调校，确保长时间书写不产生视觉疲劳。提供多套主题适配不同环境和偏好。

### 4. 功能隐藏

常用功能通过菜单栏和快捷键访问，默认界面只展示编辑区域和必要的导航结构。

### 5. 数据安全

用户文档以 Markdown 纯文本格式保存，不引入私有数据库。应用数据（设置、最近文件等）与用户正文严格分离。

## 产品边界

### 第一版包含（已全部实现）

- 单文档打开 / 保存 / 另存为
- 所见即所得 Markdown 编辑（Milkdown + ProseMirror）
- 工作区文件树（打开文件夹，递归扫描 .md）
- 文档大纲（可折叠树形导航，点击定位）
- 多主题切换（暖白 / 墨夜 / 海雾 / 玫砂）
- 浅色 / 深色模式
- 查找替换（支持正则）
- 字数统计 + 行数 + 阅读时长
- 写作统计（近7天字数趋势 + 写作时长）
- 分栏预览（编辑↔预览按比例同步滚动）
- 专注模式（F11 隐藏所有 UI）
- 打字机模式（光标行始终居中）
- 代码块悬浮操作层（语言修改 + 一键复制）
- 数学公式（KaTeX，动态加载插件）
- Mermaid 图表（动态加载插件）
- 脚注（[^标签] 引用 + 定义）
- 图片管理面板（网格预览 + 删除）
- 自动保存（30秒间隔，可开关）
- 草稿自动恢复（崩溃/重启后恢复未保存内容）
- 会话恢复（重启恢复打开的文件与激活文档）
- 外部冲突检测（mtime 校验，弹确认）
- 无边框一体化顶栏（Windows，系统按钮区颜色随主题同步）
- 设置面板（Typora 式分类导航）
- 帮助系统（快捷键 / 语法 / 写作统计 / 关于）
- 导出 PDF / HTML
- Windows 安装包

## 成功指标

- 启动到可编辑状态 < 2 秒
- 1MB 文档编辑流畅无卡顿
- 崩溃后数据恢复 RPO < 5 秒
- 连续使用 2 周无数据丢失
