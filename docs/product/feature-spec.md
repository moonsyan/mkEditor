**已知限制**：

- 演示文件（左侧树中的 7 篇）编辑内容存内存 + 草稿，重启后通过草稿恢复；磁盘文件可正常保存并自动备份
- 粘贴的图片存储位置：文档旁 `attachments/` → 工作区 `attachments/` → 用户数据目录；文档内以相对路径存储（可移植），编辑器渲染时解析为 `mdimg://` 本地协议
- 设置持久化存储于用户数据目录 `settings.json`，当前保存主题/自动保存/拼写检查/多窗口模式/字号/内容宽度/行距/内容字体/缩放/侧栏宽度/文件树折叠状态/侧栏活动页/写作统计/最近文件/快捷键/会话/草稿
- 大纲提取会跳过代码块内的 `#`；引用块内标题（`> # x`）已支持并参与大纲/跟随高亮
- 工作区搜索缓存符合 mtime 和大小未变化的文件行；最多扫描 500 个文件、单文件 2MB、返回 200 条命中，超出时会截断；正则在 Worker 中逐文件匹配，单文件超过 500ms 会终止并提示简化表达式
- 属性面板仅将简单的单行 YAML 键值结构化编辑；复杂嵌套对象、数组和多行值保留原文，不展开为表单
- Wiki 链接只在当前工作区内解析已有文件，目标不存在时提示，不自动创建文件

## 阶段 0：编辑器技术验证

**目标**：验证 Milkdown 作为编辑器内核的可行性。

### Spike A：基础编辑

- Milkdown 初始化和销毁
- 标题、段落、强调、列表、引用、代码块
- 中文 IME、撤销重做、复制粘贴
- 编辑器命令和键盘快捷键

### Spike B：Markdown 往返

- 建立 50 个 fixture 测试用例
- 语义等价和格式幂等测试
- CRLF、BOM、中文、emoji 和代码 fence

### Spike C：关键体验

- 当前块标记显隐原型
- 图片 NodeView 原型
- 100KB / 500KB / 1MB 性能测试

### 退出条件

- Profile Core fixture 全部通过
- 中文输入和核心交互无阻断问题
- Milkdown 通过 ADR-003 验收门槛

## 阶段 1：单文档安全 MVP

**目标**：可以安全地打开和保存单个 Markdown 文件。

### 功能清单

| 功能 | 说明 |
|------|------|
| 打开文件 | 通过文件对话框选择 .md 文件 |
| 保存 / 另存为 | 原子写入，不丢失数据 |
| 所见即所得编辑 | Milkdown 渲染引擎 |
| Dirty 状态 | 标记未保存变化，退出前确认 |
| 保存中状态 | 防止并行写盘 |
| 保存失败 | 错误提示，不清 dirty |
| 外部冲突 | 检测外部修改，不静默覆盖 |
