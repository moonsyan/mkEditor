## Markdown 快捷输入（✅ 全部由 Milkdown inputRules 提供）

在编辑器中直接输入 Markdown 语法，即时渲染：

| 输入 | 效果 |
|------|------|
| `# ` + 回车 | 一级标题 |
| `## ` + 回车 | 二级标题 |
| `### ` + 回车 | 三级标题 |
| `- ` + 回车 | 无序列表 |
| `1. ` + 回车 | 有序列表 |
| `> ` + 回车 | 引用块 |
| `- [ ] ` + 回车 | 任务列表 |
| `---` + 回车 | 分割线 |
| ` ``` ` + 回车 | 代码块 |
| ` ```python ` + 空格/回车 | 指定语言的代码块（也可用 `~~~python`，语言名大小写均可） |
| `$E = mc^2$` | 行内数学公式（KaTeX，检测到 $ 后自动加载插件） |
| `$$` + 回车 | 块级数学公式 |
| ` ```mermaid ` + 回车 | Mermaid 流程图（检测到 mermaid 后自动加载插件） |
| `[^标签]` | 脚注引用；行首 `[^标签]: 内容` 为脚注定义 |

**代码块内导航**：光标在代码块最后一行按 `↓` 退出到块后（无块则新建段落），在第一行按 `↑` 退出到块前（Typora 同款）。
