# MarkdownSoft vs Typora 功能对比分析

> 更新日期：2026-08-09  
> 对比版本：MarkdownSoft v0.0.1（当前实现）vs Typora v1.0+

---

## 概览

| 维度 | MarkdownSoft | Typora | 说明 |
|------|-------------|--------|------|
| 价格 | **免费开源** | 付费（$14.99） | MarkdownSoft 完全免费，无许可限制 |
| 运行环境 | Electron（Windows 优先） | Electron（Win/Mac/Linux） | 二者同为 Electron 应用 |
| 编辑器内核 | Milkdown（ProseMirror） | 自研引擎 | Milkdown 基于 ProseMirror，扩展性更强 |
| 安装包大小 | ~150MB | ~120MB | Electron 应用均较大 |
| 内存占用 | ~200MB 启动 | ~180MB 启动 | 相近量级 |
| 主题数量 | 4 套（可自定义） | 3 套（可自定义） | 数量相近，均可 CSS 扩展 |
| 插件系统 | ❌ 无 | ✅ 有 | Typora 插件生态丰富，MarkdownSoft 功能内置 |

## 核心编辑体验对比

| 功能 | MarkdownSoft | Typora | 差异说明 |
|------|:---:|:---:|------|
| 所见即所得 | ✅ | ✅ | 均即时渲染 Markdown 语法 |
| 块级上下文标记 | ⚠️ 部分 | ✅ | Typora 更完善的"当前块"视觉提示 |
| Markdown 快捷输入 | ✅ | ✅ | 均支持 `# `、`- `、`> ` 等回车即渲染 |

| 数学公式（KaTeX） | ✅ 动态加载 | ✅ | MarkdownSoft 按需加载插件，启动更快 |
| Mermaid 图表 | ✅ 动态加载 | ❌（需插件） | MarkdownSoft 内置，Typora 需自行安装插件 |
| 脚注 | ✅ 自建节点 | ✅ | 二者均支持 |
| 任务列表 | ✅ | ✅ | 均支持 `- [ ]` / `- [x]` |
| 表格编辑 | ✅ 行列增删 | ✅ 可视化编辑 | Typora 表格可视化更强（边框拖拽） |
| 公式/图表动态加载 | ✅ | N/A | MarkdownSoft 检测到 `$` / `mermaid` 后才加载插件，降低启动内存 |

## 总结

MarkdownSoft 在以下方面已接近或超越 Typora：
- 核心所见即所得编辑体验
- 文件安全（冲突检测、草稿恢复、退出保护）
- 写作统计与习惯追踪
- 代码块操作体验（轻量悬浮层）
- 价格（完全免费）

MarkdownSoft 与 Typora 的主要差距在：
- **多标签页**（当前为文件列表切换，非 Tab UI）
- **代码折叠**（段落折叠交互）
- **前后缀匹配高亮**（括号/引号配对）
- **插件生态**（功能需全部内置，扩展性受限）
- **跨平台**（当前仅 Windows）

整体定位：**面向写作者的免费替代方案**，核心写作体验对标 Typora，在文件安全、写作统计、代码块体验上有独有优势；多标签、插件等高级功能将在后续阶段迭代。
