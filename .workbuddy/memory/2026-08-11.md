# 2026-08-11

## MarkdownSoft 标签页/启动体验修复（mk-editormkEditor）

针对用户反馈的 4 个体验问题进行了修改（均在渲染进程）：

1. **标签页只在编辑器区**：`Sidebar` 移除了「已打开」圆点（`tree-open-dot`）、「外部文件」区块、「新建文档」区块，打开文件统一由编辑器区 `TabBar` 呈现；左侧仅保留文件夹树 + 大纲。
2. **关闭最后一个 tab 关不掉**：`handleCloseTab` / `handleDeleteFile` 关掉最后一个标签时不再 `handleNew()` 自动新建空白文档，改为允许 `openFiles` 为空并显示 `StartScreen`（开始界面，含 新建/打开文件/打开文件夹 入口）。编辑器实例保持挂载不卸载。
3. **不要最近打开文件**：即第 1 点的「外部文件」区块移除。
4. **启动不要铺开一堆 tab**：`INITIAL_FILES` 改为只预开 `welcome` 一篇样例；其余样例文件留在左侧文件夹树，点击通过新增的 `handleSelectDemoFile`（未打开则打开为新标签）按需打开。

新增组件 `src/renderer/src/components/StartScreen/index.tsx`；`global.css` 增加 `.editor-host` / `.start-screen` 样式；`App.tsx` 用 `.editor-host` 包裹 Editor+预览+StartScreen，`doc-title` 在空状态时隐藏，`activeContent` 空状态时归零，会话持久化 `activeFileId` 在空状态时写 undefined。

验证：`tsc -p tsconfig.web.json` 通过（无类型错误）。
