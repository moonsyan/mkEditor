## 完成「功能文档与对比分析.md」高优先级未实现功能（对标 Typora，7 项）
依据文档第 5.1 节高优先级清单，补齐 7 个此前未实现的功能，全部采用最小改动、单文档内核不变：

1. **多标签页编辑** `src/renderer/src/components/TabBar/index.tsx`（新）+ `tabbar.css`（新）+ `App.tsx` 接入：复用现有 `openFiles/activeFileId/switchFile`，新增 `<TabBar>` 渲染标签条，支持点击切换、`×` 关闭（未保存时 `window.confirm` 确认）、HTML5 拖拽排序（`onReorder` → `handleReorderTabs` 用 splice 重排）。`main.tsx` 引入 `tabbar.css`。
2. **代码折叠（标题段落折叠）** `Editor/index.tsx` 新增 `sectionFoldPlugin`：用 `Decoration.widget` 在标题左侧渲染 `▾/▸` 折叠标记，`mousedown` 派发 `setMeta(sectionFoldKey,{toggle:start})`；已折叠区块用 `Decoration.node` 加 `.folded-hidden{display:none}` 隐藏（直到下个同级/更高级标题）。折叠位置存 `Set<number>`，文档变化时重映射。
3. **前后缀匹配高亮** `Editor/index.tsx` 新增 `bracketMatchPlugin`：`matchPairAt` 匹配 `()[]{}` 与双引号配对，`buildBracketDecos` 按光标 `parentOffset`（cursor-1 或 cursor）取两端加 `.bracket-match` inline 装饰。
4. **块级上下文标记** `Editor/index.tsx` 新增 `blockContextPlugin`：找光标所在顶层块加 `.block-active` node 装饰；`tr.docChanged||tr.selectionSet` 时重建。
5/6/7. **正文字号/内容宽度/行距精细调节**：设置模型由档位联合类型改为数值（`FontSize/ContentWidth/LineHeight` 均为 number）。`SettingsDialog` 改为「预设 seg 按钮 + `<input type=range class=fine-slider>` 滑块」：字号 12-24/步1、宽度 480-1400/步20、行距 1.2-2.6/步0.05。`editor.css` 的 `.editor-inner` 改用 CSS 变量 `--efs/--ecw/--elh`（保留 `*var(--editor-zoom,1)` 缩放）。`App.tsx` 加载时兼容旧档位字符串→数值，应用改为 `document.documentElement.style.setProperty('--efs/--ecw/--elh',...)` 并持久化新数值。`settings.css` 新增 `.fine-slider` 样式。

三处编辑器插件均挂在 `.use($prose(...))` 链上（紧接 lineNumPlugin 之后）。行为已按现有 searchPlugin/nodeAttrsPlugin/lineNumPlugin 的同款 `new Plugin({key,state,props})` 模式编写，类型用 `@milkdown/kit/prose/state|view` 的导出（与同文件一致）。
