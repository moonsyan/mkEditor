# Java 开发者的前端学习路线

> 标签：#markdown编辑器 #前端 #typescript #学习路线
> 日期：2026-08-06

## 学习原则

不需要先学完整前端生态。围绕当前项目逐层学习，每层都做一个小实验。你已有的类型、接口、分层、测试和异常处理经验可以复用，但浏览器事件、DOM、不可变状态和编辑器 selection 是新领域。

## Java 概念映射

| Java 经验 | TypeScript/Electron 对应 | 关键差异 |
| --- | --- | --- |
| interface/DTO | TypeScript type/interface | 类型运行时会被擦除，外部输入仍需校验 |
| CompletableFuture | Promise/async-await | 单线程事件循环，阻塞会卡 UI |
| Spring Controller | IPC handler | 不是 HTTP，但同样要 DTO、校验、错误映射 |
| Service 分层 | Application use case | 不需要依赖注入框架也能分层 |
| Swing/JavaFX UI | React component | 状态驱动渲染，不手工同步每个控件 |
| ORM Entity | ProseMirror Node | 文档树是不可变值，不是可随意 set 的实体 |
| Command Pattern | ProseMirror command | command 根据 state 产生 transaction |
| Transaction | ProseMirror transaction | 是文档变化描述，不是数据库事务 |

## 第 1 层：TypeScript

重点：

- 基础类型、联合、泛型、类型收窄；
- `unknown` 与运行时 schema 校验；
- module、import/export；
- Promise、async/await、错误处理；
- 不可变数组和对象；
- npm/pnpm、package.json、lockfile；
- TypeScript strict。

练习：读取一个字符串，解析成判别联合命令并返回 `Result<T, E>`，不使用 `any`。

## 第 2 层：浏览器和 React

重点：

- DOM、事件冒泡、焦点、selection；
- React component、props、state、effect、ref；
- controlled 与 uncontrolled；
- 组件生命周期和 cleanup；
- CSS 布局、flex、grid、滚动容器；
- 为什么编辑器实例放 ref，而不是频繁进入 state。

练习：实现一个带文件名、dirty 状态、保存按钮和退出确认的假编辑器，不接 ProseMirror。

## 第 3 层：Electron

重点：

- main、preload、renderer；
- BrowserWindow 生命周期；
- contextBridge 和 IPC；
- 文件对话框；
- 安全配置；
- 开发环境与生产打包差异。

练习：renderer 通过白名单 API 选择文本文件并显示，renderer 中访问不到 `fs` 和 `process`。

## 第 4 层：ProseMirror

阅读顺序：

1. Schema、Node、Mark；
2. EditorState、Transaction；
3. Selection、position、resolve；
4. Command、keymap、input rule；
5. Plugin 和 plugin state；
6. Decoration；
7. NodeView；
8. parse/serialize 和 clipboard。

练习：不用 React 控制正文，完成粗体命令、列表命令、transaction 日志和自定义图片节点。

## 第 5 层：Milkdown 与 Markdown

重点：

- Milkdown preset 和 plugin；
- Milkdown 内部的 remark/unified pipeline；
- Markdown AST 与 ProseMirror schema 映射原理，用于调试和扩展，不在应用层重写桥接；
- input rule 不等于 Markdown parser；
- roundtrip、幂等和不支持语法；
- NodeView 与 Markdown serializer 的边界。

练习：建立 10 个 fixture，执行 parse/serialize/parse 等价测试，再逐步扩充到 50 个。

## 第 6 层：真实编辑器问题

- 中文 IME composition；
- selection 映射；
- 粘贴 HTML/文本/图片；
- 撤销重做；
- 跨块 Backspace/Delete；
- 文件保存并发；
- 大文档 profile；
- Electron 安全和安装发布。

这些只能边做边学，不能只看视频掌握。

## 暂时不要学

- Next.js 和服务端渲染；
- Redux 全套生态；
- 微前端；
- GraphQL；
- WebRTC 协作；
- Rust/Tauri；
- 自研 Virtual DOM；
- 插件沙箱。

## 每周学习节奏

```text
20% 阅读官方文档
60% 小实验和项目代码
20% 测试、复盘和必要的决策记录
```

只有技术路线、跨模块契约、持久化格式或安全边界发生变化时记录 ADR；普通学习结论写进实验说明或 issue，避免文档工作挤占验证时间。

遇到编辑器问题时先制作最小复现，不在完整应用中反复猜。把新的回归样例加入 [[测试与质量策略]] 所述 fixture。
